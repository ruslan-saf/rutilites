# RuTilites

Небольшая утилита в трее Windows. Она исправляет раскладку выделенного текста, гасит экран, переводит компьютер в сон по горячей клавише и не даёт ему уснуть, когда это нужно.

## Функции

| функция | клавиши по умолчанию |
|---|---|
| Исправить раскладку выделенного текста (RU ↔ EN, включая знаки препинания) | Ctrl+Shift+X |
| Выключить / включить экран | Ctrl+Alt+F12 |
| Спящий режим | Ctrl+Alt+Q |
| Не уходить в сон (экран гаснет как обычно или не гаснет) | клик по значку |

Комбинации клавиш меняются в окне «Настройки…» (двойной щелчок по значку).

## Установка на новый ПК

Нужны Windows 10/11 и Python 3.10 или новее. Если Python нет, его можно поставить командой `winget install Python.Python.3.13` или с python.org (при установке отметьте «Add python.exe to PATH»).

1. Скачайте программу одним из способов:
   - через git: `git clone https://github.com/ruslan-saf/rutilites.git C:\GitProjects\rutilites`;
   - без git: на странице репозитория нажмите Code → Download ZIP и распакуйте архив в любую папку.
2. Дважды щёлкните `install.cmd` в папке программы.

Установщик ставит зависимости из `requirements.txt`, добавляет RuTilites в автозагрузку и запускает её. Если автозагрузка не нужна, запустите `install.ps1` с ключом `-NoAutostart`:

```powershell
powershell -ExecutionPolicy Bypass -File install.ps1 -NoAutostart
```

## Запуск, обновление, перезапуск

- Запуск вручную: двойной щелчок по `RuTilites.vbs` (окно консоли не появляется).
- Обновление: `git pull` в папке программы (или новый ZIP поверх старого), затем «Перезапустить» в меню значка. Если в новой версии изменился `requirements.txt`, сначала снова запустите `install.cmd`.
- Версия и коммит показаны в правом верхнем углу окна «Настройки…».

## Настройки и портабельность

Программа портабельная: настройки хранятся в `config.json` рядом с `main.py`, поэтому при копировании папки они переносятся вместе с ней. Файл создаётся при первом сохранении настроек и в git не попадает.

Значения по умолчанию (таблица выше, `DEFAULTS` в `config.py`) совпадают с настройками автора, так что на новом ПК программа сразу работает так же.

Если папка программы защищена от записи (например, лежит в Program Files), настройки сохраняются в `%APPDATA%\RuTilites\config.json`. Оттуда же при первом запуске однократно копируются настройки, сохранённые версиями до 1.2.0.

## Удаление

1. «Выход» в меню значка.
2. Удалите `%APPDATA%\Microsoft\Windows\Start Menu\Programs\Startup\RuTilites.vbs` (или заранее снимите «Автозапуск» в меню).
3. Удалите папку программы (и `%APPDATA%\RuTilites`, если она есть).
